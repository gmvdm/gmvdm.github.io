# Android Beta

To install the testing version on Android:
1. Join the [ZoneSlider Testers Google Group](https://groups.google.com/g/zoneslider-testers) (or email `zoneslider-testers+subscribe@googlegroups.com`).
2. Accept the test invite and download on Google Play:

[<img src="GooglePlay_Badge_Web_color_English.png" width="180">](https://play.google.com/apps/testing/com.pseudofish.zoneslider)
